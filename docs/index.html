04METHOD

How I investigate an alert.

Context. Evidence. A clear handoff.

Try the investigation demo
STAGE 01 / 10

Alert triggered

Read the detection rule, severity and trigger. Record event time and timezone before building a theory.

“What actually caused the detection?”
Alert ID · rule · event time

Read the detection rule, severity and trigger. Record event time and timezone before building a theory.

“What actually caused the detection?”
Alert ID · rule · event time

Check whether the raw events satisfy the rule. Compare the user, asset and activity with the available baseline.

“Does the evidence match the alert?”
Raw trigger · baseline · log coverage

Read the original records, preserve event references and arrange the relevant activity chronologically.

“Which observations support or contradict my hypothesis?”
Evidence references · correlated timeline

Pivot across authentication, identity and endpoint context. Correlate logon type, privilege, device and session.

“Do these events belong to the same activity?”
Identity · endpoint · source IP

Use reputation and enrichment as supporting context. An unknown or clean reputation does not establish safety.

“What does enrichment add, and what can’t it prove?”
Lookup source · result · time

Search related users, hosts and indicators over a defined time range. Separate confirmed scope from missing coverage.

“What is affected, and what remains unknown?”
Time window · affected entities · gaps

Choose true positive, false positive, benign positive or needs more investigation. Explain confidence and contradictions.

“Can another analyst follow the reasoning?”
Verdict · confidence · evidence

Propose proportionate next actions under the playbook. Keep recommended containment separate from actions actually taken.

“What should happen next, and who is authorized?”
Action status · recommendation · owner

Summarize context, sources, scope, verdict and action status. Make the handoff repeatable with precise evidence references.

“Could someone reproduce this investigation?”
Case notes · references · next step

Escalate possible compromise, privileged account impact, spread or material uncertainty. State the risk and exact help needed.

“What decision requires the next response tier?”
Escalation reason · impact · request
